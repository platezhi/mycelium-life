# Mycelium Life

Эксперимент с виртуальной грибоподобной колонией. 100 исходных клеток; возрастная смерть через 7 виртуальных суток; базовое накопление ресурса для деления за 14 виртуальных суток при 100% поступлении энергии; при избытке энергии деление ускоряется. Цифровая ДНК содержит 6 наследуемых параметров, сигналы клетки троичные (-1, 0, +1). Упрощённая модель, не биологическая симуляция грибного генома.

**Время:** 1 виртуальные сутки = 3 реальные минуты. GitHub Actions запускается по расписанию приблизительно каждые 5 минут и догоняет пропущенное время. Расчёт может запаздывать. В отсутствие работающего GitHub Actions эволюция не идёт.

## Запуск

1. Распаковать содержимое архива в корень публичного репозитория GitHub, включая скрытую папку `.github/workflows`.
2. В Settings → Actions → General разрешить выполнение GitHub Actions и запись workflow (Workflow permissions: Read and write permissions), если это требуется настройками репозитория.
3. В Actions → Evolve virtual mycelium нажать Run workflow. Это создаст `state.json`.
4. В Settings → Pages выбрать Deploy from a branch → main → /(root) → Save.
5. После публикации открыть `https://platezhi.github.io/mycelium-life/`.

Изменение `config.json` позволяет задать процент поступления энергии. Состояние сохраняется в `state.json` в GitHub, а история изменений — в Git-коммитах. По умолчанию 200%. **Внимание:** 100% энергии при сроке жизни 7 суток и цикле деления 14 суток обычно приводит к вымиранию. В модели нет автоматического возрождения после вымирания.

**Ограничения:** нет полноценной нейросети, нет реального грибного генома, нет истинного ощущения удовольствия/боли; цифровая ДНК и локальные правила — только первая экспериментальная модель. Клетки пока не обмениваются энергией напрямую. Количество ограничено 500.
